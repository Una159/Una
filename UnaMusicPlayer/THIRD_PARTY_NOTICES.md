## Required release procedure

1. Use the committed `CloudflareGateway/package-lock.json` and `npm ci` for reproducible installs; update it only through a reviewed dependency change.
2. Download the CycloneDX SBOM artifact from the corresponding successful Una Gateway Validation run and retain it with the release record.
3. Review every direct and transitive dependency's exact version, license text, advisories and maintenance status; specifically assess the optional LGPL-3.0-or-later libvips packages in the Wrangler toolchain tree.
4. Add required license texts and notices for any dependency distributed with the release.
5. Record each deployed provider adapter's repository URL, immutable commit/tag, license, attribution and deployment owner.
6. Re-check all artwork, fonts, sounds and other bundled assets.
7. Update this document with the verified results before public distribution.
